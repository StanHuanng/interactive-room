# 室内场景详细描述（用户提供，2026-10-14）

## 01 红色沙发（Lounge Chair & Ottoman）
- 位于房间左前方，靠近左侧深胡桃木书架，在办公桌左前侧；略朝房间中央。
- 宽大低矮的单人休闲扶手椅 + 独立脚凳（脚凳在沙发右前方），同在浅棕色地毯上。
- 现代有机曲线：宽厚靠背，顶部连续圆弧；扶手饱满，与靠背自然连接；坐垫宽深、坐高低；底座贴地，椅脚基本隐藏。
- 脚凳：不规则椭圆，厚实，顶部略隆起。
- 面料：深酒红偏赤褐 Bouclé 圈圈绒。主体 #632D28，受光 #874439，阴影 #3B1D1C。低饱和、带棕调，非鲜红；细密不规则绒圈纹理，粗糙柔软，无塑料反光。
- 沙发左侧：小型金属边桌 + 蘑菇形暖光台灯（乳白半球灯罩、金色灯柱）。
- 氛围：书架灯带、台灯、环境暖光；靠背上缘与扶手有柔和橙金高光，内侧底部深红褐阴影。

## 02 办公桌（Executive Desk）
- 房间中央偏后，正对观察者，横向摆放，为视觉中心。后方米色墙、软木公告板、深色木质矮柜。
- 宽大长方形，桌面薄、平整、边缘平直（直角或极小圆角）；深胡桃木，细腻天然木纹。
- 桌下无抽屉、无封闭储物。两端为宽大的银灰拉丝不锈钢板式桌腿（近垂直矩形板），柔和反射，不像镜子。
- 颜色：深胡桃木 #493025，金属银灰 #8C8580，木材阴影 #261A17。
- 桌面陈设：中间银色一体机（经典 iMac 造型，已有模型保留）；左侧黄铜/香槟金蘑菇台灯（低矮半球灯罩）；电脑左右少量横向叠放书籍（米白、棕、灰）；小木托盘、陶瓷器皿、笔筒。整齐但有使用痕迹。
- 办公椅：在桌前正中，棕色皮革 + 银色金属框架；低弧形靠背；座椅与靠背厚皮革软垫；扶手为银色金属支架 + 棕色皮革；银色五爪旋转底座带脚轮；椅背朝观察者，正面朝电脑。
- 风格：Mid-Century Modern + 当代极简。

## 03 墙壁与建筑细节
- 主墙：暖米/沙色，哑光乳胶漆或微水泥，平整。基础 #B99475，受光 #D4AB83，阴影 #8B634B。
- 左墙：大面积深胡桃木定制书架与木饰面，高低不同开放格，接近天花板；书、相框、陶瓷、雕塑、少量绿植；层板下暖色 LED 灯带向下照射，金橙光晕；旁有竖向壁灯（细长暖白灯罩、黄铜外框）；竖向木纹。
- 中央背景墙：桌后，大型横向软木公告板（浅棕软木颗粒、深木边框），钉有大幅复古地图、数张小风景照、便签、卡片纸张，布局不对称。公告板左侧竖向抽象画（米白、棕黑几何色块，细窄深色画框）。
- 右墙：公告板右边深胡桃木单开门（平整、竖向深色木纹、简洁金属把手）；门右侧米色墙挂另一幅竖向抽象几何画；最右为窗户（深棕窗框）+ 窄木书架，旁有落地灯和盆栽。
- 天花板：平整浅米色，无复杂吊顶；暖色间接光形成琥珀光晕。
- 照明色温 2400–3000K；柔和渐变，避免均匀照亮，避免过强橙色滤镜使物体失真。

## 04 木地板与地毯
- 深棕实木宽长条地板（深胡桃/深橡木），细微拼缝，沿长度方向木纹，不完全重复。
- 颜色：基础 #543020，暖光反射 #91502B，暗部 #2B1B16；带红褐调；木板间轻微色差。
- 低光泽半哑光清漆，少量柔和镜面反射，非抛光镜面；不可渲染为纯黑或纯棕平面。
- 光照：书架灯带、桌面台灯、右侧落地灯、顶部环境光在地面形成金橙反射；前景较暗，中间及右侧柔和光斑和细长反射。
- 中央地毯：大面积长方形浅棕织物（亚麻/沙棕/浅焦糖），明显比地板浅；细密粗糙天然纤维编织，轻微平行条纹和色差；薄，贴地，非长毛绒。覆盖办公椅、桌前和脚凳周围，延伸到桌下。

## 06 Web 交互：Mac 与 ESP32 文章卡片

本次仅增加以下两种交互；保留既有行走、办公椅与沙发功能。所有改动仅作用于 Web，**不得修改 `public/models/mac.glb`**。

- **Mac / X 个人页**：点击电脑任意部位或屏幕，以指数缓动移动位置、四元数插值旋转和视角缓动，正对屏幕；根据窗口宽高比适配构图。屏幕使用 drei `Html transform occlude`，尺寸 0.56 × 0.285 m、局部中心 `[0, 0.381, -0.126]`，在原 GLB 屏幕前方 3 mm，保留机身和边框。页面为风格化预览：`1psum Stan`、`@1psumesse`、头像占位、简介占位和 3 条明确标注的帖子占位。`View on X` 链接指向 `https://x.com/1psumesse`，新标签打开并带 `noopener noreferrer`。悬停有柔和边缘高亮和手形光标。
- **毛毡板 / 文章卡片**：沿用原公告板的世界位置 `[0, 1.65, -2.43]` 和 1.86 × 0.93 m 深胡桃木边框比例。Web 复用原 GLB 边框的倒角与木纹法线，以程序几何替代旧软木板内容，使用灰橄榄色毛毡、细密纤维凹凸、一张奶油纸卡和酒红图钉；不叠放旧地图和便签。纸卡局部位置、轻微旋转及尺寸记录在 `scene-layout.json` 的 `corkboard.articleCard` 中，供 Web 读取；新增元数据不影响既有 Blender 布局读取。悬停时纸卡平滑抬起并轻微摆动，纸面暖光增强、光标变为手形。点击后纸卡从墙面飞至镜头前并转向读者，约 0.4 秒后阅读面板淡入；关闭时卡片平滑飞回原位。
- **文章内容**：`src/data/esp32Article.ts` 保存从 `/workspace/x-article/v7-gpt/draft.md` 提炼的标题和 3 句中文摘要，无运行时文件依赖。标题为「原来，Claude 早就给 ESP32 留了个按钮」。摘要区分 Buddy 的实体审批、小智的 MCP 执行，以及尚需开发 listener 的云端桥接方案。原文按钮保留 `href="#"`，阻止默认锚点跳转，标注“原文链接待补充”；原始 X URL 的 TODO 留在数据文件中。
- **返回与输入**：Escape、关闭按钮或点击内容外侧退出。Mac 从任意站立或坐姿进入时，保存实际镜头位置、朝向与 FOV，退出时缓动返回；浏览期间暂停行走和座位切换。文章不移动镜头，关闭面板时卡片仍继续缓动归位。Pointer lock 仅在行走时启用，鼠标解锁时使用正常位置射线；锁定时使用中央射线。清空按键状态以避免退出预览后继续移动。
- **阅读与键盘**：阅读面板在小窗口可滚动，含中文语言标记、dialog 语义、延迟焦点与 Tab 焦点循环。页面另有仅在键盘聚焦时出现的两个入口，对应上述同一组场景交互。
- **性能与动画**：镜头和卡片使用与帧率无关的指数缓动，帧间隔上限 50 ms，位置/朝向/FOV 连续变化；动画循环复用向量、四元数及矩阵，无逐帧临时对象。毛毡和纸纹在初始化时用 CanvasTexture 生成并在卸载时释放，无外部图片或字体请求；使用低面数几何，无额外后处理。

验证命令：`npm run typecheck`、`npm run lint`、`npm run build`。本次环境禁止监听本地端口且 Chromium 启动被沙箱阻止，因此浏览器视觉与真实点击验收仍需在可运行浏览器的环境进行；构图与动画逻辑另用真实 Three.js 数学对象做数值检查。
